# Source mapping and conformance limits

These anchors refer to the public runtime source shipped at `a536957108a12d61bf6962fb7fe08bd6b7175375` and retained unchanged with this addition. [source-mapping.json](source-mapping.json) records exact public file hashes. Names and hashes aid review; they do not prove simulation/refinement or that a runtime action implements every abstract transition.

| Abstract responsibility | Public source anchors | Limits |
|---|---|---|
| Allocation exclusion and durable ownership | `Service.reserve`, `Service.release`, `Service.reconcile` in [service.py](../../src/nodus_dc/service.py); resource overlap in [model.py](../../src/nodus_dc/model.py); SQLite/locking in [store.py](../../src/nodus_dc/store.py) | Model partitions/budgets are symbolic. The local service uses exclusive physical pool leases; cooperating sharing clients are subclients of that lease, not independent overlapping allocations. No arbitrary multi-host hierarchy is modeled. |
| External claims, fencing and cleanup | `Service.bridge_claim`, `bridge_reclaim`, `bridge_complete` in [service.py](../../src/nodus_dc/service.py); permission freshness in [connection.py](../../src/nodus_dc/connection.py) | Real companion node-agent enforcement, privileged launch paths, remote consent, device handles and hardware cleanup require independent qualification. Model generations are finite and do not prove distributed clock bounds. |
| Native terminal return | `Handback.run`, `LinuxAgent.stop` in [handback.py](../../src/nodus_dc/handback.py); introduced-key obligations and positive recovery evidence in [recovery.py](../../src/nodus_dc/recovery.py) | The model abstracts protocol parsing, audit pagination and actual API/authentication-cache behavior. It excludes malicious host root, physical reimage, re-enrollment, native login and new lending after customer root access. |
| Financial lineage and replay | [financial.py](financial.py) and [integrated.py](integrated.py) state the abstract contract | This standalone package is **not** the hosted financial ledger or payment processor. No local implementation conformance anchor is claimed for settlement, transfer or bank payout. These published models are reviewable requirements, not proof of any hosted deployment. |

The runtime test files use real SQLite/private files with simulated external or hardware responses. The separate systemd qualification concerns representative workers. Those results have their own artifact identities and limits; they are not converted into model conformance here. All GPU, hosted retirement, native-access and payment requirements remain independently qualified or unqualified according to their own evidence.
